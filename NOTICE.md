# Notices and credits

Leadsmith is original code. These open-source projects informed its design. Where a pattern was adapted, the original license is reproduced below.

- **Harvey**, by Ethan Rogers. <https://github.com/ethanplusai/harvey>, MIT.
  Adapted: signals as provenance-carrying observations, the HTML tech-fingerprint approach (`providers/techdetect.py`), and several cold-email writing and spam-word rules (`lint.py`).
- **claude-outreach**, by Emelia. <https://github.com/emelia-io/claude-outreach>, MIT.
  Adapted: mechanical copy checks (subject length, spam triggers, link limits, placeholders) in `lint.py`, and the "count before you spend credits, keep provenance on every row" discipline in the agents.
- **4ruple** by Basement Protocol. <https://basementprotocol.com/4ruple>. Product inspiration only (no code): a local app driven by the user's own Claude Code, firm → leads → review → outreach, Gmail sending with test-to-self, PDF decks, local data.
- **gtm-eng-skills** by Aero (<https://github.com/getaero-io/gtm-eng-skills>), **growth-engineer** by Brew (<https://github.com/GetBrew/growth-engineer>) and **gtm-system** by La Growth Machine (<https://github.com/LaGrowthMachine/gtm-system>), all MIT. These were reference material for signal-discovery plays and agent/skill structure. No code copied.
- **OpenOutreach** by eracle. <https://github.com/eracle/OpenOutreach>, GPL-3.0. Feature inspiration only (no code): learning from the user's lead verdicts, business-hours sending, a reply assistant and a compliance notice.
